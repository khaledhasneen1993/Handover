# Design system

Reference images supplied by the product owner guide the interface. Do not reuse their embedded car/phone/property photographs as stock assets; show real users' photos or explicit placeholders.

| Token | Light value | Use |
|---|---|---|
| Navy | #102C48 | Headers, principal typography |
| Teal | #008E9A | Main CTA, selected controls |
| Teal light | #DDF4F5 | Selected items, light labels |
| Background | #F7FAFC | Neutral canvas |
| Amber | #D18C32 | Incomplete / awaiting status |
| Error | #B42318 | Deletion and destructive errors only |

Spacing scale 4/8/12/16/20/24dp, rounded cards 22dp and CTAs 18dp. Material3 dynamic typography and TalkBack labels. Product screenshots: home with cards, category picker, guided camera with reference overlay, image annotation, comparison, report preview, and point checklist. Actual device screenshots and WCAG contrast measurements are release gates; not generated from mockups.
